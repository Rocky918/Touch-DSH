# Touch DSH test matrix

Every public beta should cover:

| Edition | Architecture | Touch Bar | Status |
| --- | --- | --- | --- |
| Touch DSH | Intel | Present | Locally verified |
| Touch DSH | Apple silicon | Present | External hardware needed |
| Touch DSH Menu | Intel | Not used | Testing needed |
| Touch DSH Menu | Apple silicon | Absent | External hardware needed |

Test first launch, all status colors, DSH start/open/stop, force-stop protection, launch at login, log permissions and rotation, sleep/wake, network recovery, and media playback interactions. Sanitize all logs before sharing them.
